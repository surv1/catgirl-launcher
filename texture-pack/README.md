# Catgirl Pack

A free texture pack for Minecraft 1.21.11: animated swords, axes and mace, pink enchant glint,
catgirl armour, heart/paw totem sparkles, a catgirl totem, and new sounds. Everything is drawn or
synthesised by the scripts in `tools/`.

Build: `python3 tools/build_pack.py src/skin.png out/` (needs Pillow, numpy, scipy, ffmpeg).
The download lives at `docs/downloads/CatgirlPack.zip`; the "Texture pack check" workflow tests that
zip against the real game every time it changes.
