CatgirlClient

A cosy Minecraft launcher that's actually cute. Play any version, add mods in one click, and dress the whole thing up in your colours.

Download for Windows See what's inside

Free for Windows 10 and 11. You need Minecraft: Java Edition.

Everything a cosy launcher needs

Built for players who want Minecraft to feel like theirs, from the launcher all the way to the title screen.

Make it yours

Twelve themes, or pick any colour you like. Add a background, choose a font, and move the menu wherever feels right.

  • Custom colour picker for background and accent
  • Built-in catgirl art, your own picture, or any image link
  • Cute fonts, or any font on your PC
  • Menu on the left, right, top or bottom

Mods in one click

Search Modrinth from inside the launcher. You only see mods made for your instance, and anything they need comes along too.

  • Every Minecraft version, Vanilla or Fabric
  • Whole modpacks in one click
  • Change version and your mods update to match
  • Java downloads itself, so there's nothing to set up

Cute in-game too

Fabric instances get the CatGirl title screen: your name in the corner, a quick menu, and a catgirl fact in the yellow splash text every time.

  • Over 90 catgirl and cat facts
  • The game window is called CatGirl Client
  • Your controls, FOV and server list follow you to every instance

Get Catgirl Launcher

Up and running in a minute

No setup, no Java, no fuss.

  1. Download

    Grab the installer with the button above and open it. If Windows says "Windows protected your PC", click More info, then Run anyway.

  2. Sign in

    Add your Microsoft account. The launcher shows a short code; type it on Microsoft's page and you're in.

  3. Make an instance and play

    Pick a Minecraft version, choose Fabric if you want mods, and press Play. The first launch takes a few minutes.

You'll need Windows 10 or 11 and a Microsoft account that owns Minecraft: Java Edition. Updates install themselves.
